AGRINHO 2026

Este site foi desenvolvido pelo aluno Leonardo Silva Scheller, para o trabalho na disciplina de Educação Digital da professora Tatyanne Roiek Lazier.
Este site tem como seu objetivo mostrar como o agro se conecta com a tecnologia, atendendo ao tema do AGRINHO 2026:Agro forte, futuro sustentável.
 Justificativa: A justificativa para esse site se deve ao fato do desconhecimento da população, sobre como as tecnologias se conectam ao campo.
 A IA foi usada para auxílio na programação.
